# 寒湿腰痛膏摩方案 · 数智化展示站点

基于朱丹溪磨腰膏介质干预非特异性（寒湿）腰痛的数智化展示站点：以 **2 种设计模式 × 6 套背景方案** 生成 **12 个可独立打开的单文件站点**，把病例资料、研究思路与数据图表集中呈现，用于技能大赛项目展示与教学交流。

- 在线访问：<https://cxnlove.github.io/moyaogo/>
- 本地打开：把本仓库全部文件下载到同一目录后，双击 `index.html`
- 指导老师：**王丹**、**张洪冠**

---

## 一、项目背景

「磨腰膏」见于朱丹溪一脉的中医外治经验，以介质（膏摩）方式干预腰部。本项目面向**非特异性腰痛（寒湿腰痛证）**这一临床常见问题，把中医辨证思路、干预方案、真实病例资料与可量化的检验数据整合为一个可视化站点，便于在技能大赛、课堂讲解与同行交流中直接演示。

内容以两份赛事/研究材料为基础编写：病例资料来自《寒湿腰痛 · 技能大赛病例》，研究思路与介质干预依据来自《基于朱丹溪磨腰膏介质干预非特异性腰痛》。站点对其中涉及的处方、操作与数据均按原文呈现，未作数值改写。

## 二、快速开始

**在线看**：直接打开 <https://cxnlove.github.io/moyaogo/>，根地址即入口总览页，手机与电脑均可浏览。

**本地看**：把仓库内 13 个文件下载到**同一个目录**，双击 `index.html` 即可；不要只单独拷走某一个站点文件。

入口页列出 12 张卡片，点任意一张进入对应站点。所有站点都是单个 HTML 文件，内含全部样式、脚本与图形，**无需联网、无需安装任何环境**。

两种设计模式的区别：

- **液态玻璃（Liquid Glass）**：深色底、大圆角卡片、毛玻璃与液态玻璃双层叠加、柔和多层阴影、居中宽松排版，整体偏展台感。
- **硬边玻璃（Grid）**：浅色纸感底、小圆角、2px 实色描边加偏移实色阴影、网格底纹、紧凑左对齐，整体偏版面感。

六套背景方案只改变底色与动效气质，**正文内容完全一致**，可按演示场合挑选最合适的一套。

## 四、页面内容结构

每个站点是同一份内容、六套配色，按六个页段自上而下展开，滚动时**主色随页段自动切换**：

1. **封面** —— 项目名称、赛事场景与一句话定位
2. **方案介绍** —— 朱丹溪磨腰膏作为介质干预寒湿腰痛的基本思路
3. **案例分析** —— 三个入口，点击后进入覆盖式阅读视图，一例一页，左右翻页
4. **数据统计** —— 以图表呈现检验与体征数据
5. **近一年相关知识** —— 八个知识条目，附公开来源链接
6. **边界与来源** —— 适用范围、方法边界与来源说明

## 五、技术实现要点

- **单文件**：每个站点为一个 `.html`，样式、脚本、图形全部内联；直接双击即可打开。
- **零外部依赖**：不引用任何 CDN、字体、统计脚本，页面不发起任何外部网络请求，断网可用。
- **无跟踪、无存储**：不写本地存储、不设 Cookie、不弹窗，纯展示。
- **图表**：全部为内联 SVG 与 Canvas 绘制，未使用图表库。
- **响应式**：320px 至 2560px 宽度下均无页面级横向滚动，手机与桌面同一份文件。
- **动效克制**：背景动效为 Canvas 绘制；系统开启"减弱动态效果"时自动降级。

## 六、目录与命名约定

仓库根目录**只放本站点文件，且必须保持同一层**：入口固定为 `index.html`，各站点固定为 `site-NN-模式-方案.html`，站内跳转全部使用相对链接。因此：

- 不要重命名 `index.html`，否则根地址会打不开；
- 不要把文件放进子目录，否则入口页的链接会失效；
- 仓库中不要删除任意一个 `site-*.html`，入口页对应卡片会失效。

页面的静态托管使用仓库 `main` 分支根目录（GitHub Pages）。
